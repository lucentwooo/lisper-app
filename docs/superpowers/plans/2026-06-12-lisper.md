# Lisper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Native macOS menu-bar voice-dictation app (Wispr Flow clone): hold Fn → speak → Groq Whisper transcribes → Groq LLM cleans → text inserted at cursor; local SQLite history + speaking-coach dashboard; cinematic black/blue-glow/grain aesthetic.

**Architecture:** SPM-only (no Xcode). `LisperKit` library holds all testable logic (stats, cleanup, prompts, store, Groq client, pipeline). `Lisper` executable holds AppKit/SwiftUI shell (hotkey, audio, paste, pill, windows). Engines behind `TranscriptionEngine`/`CleanupEngine` protocols with fallback chain Groq → Apple(SFSpeechRecognizer on-device) → rules.

**Tech Stack:** Swift 6.2 (language mode v5), SwiftUI + AppKit, AVFoundation, Speech, Swift Charts, GRDB 7 (SQLite), Groq API (whisper-large-v3-turbo + llama-3.3-70b-versatile), URLSession.

**Spec:** `docs/superpowers/specs/2026-06-12-lisper-design.md` — read it before starting any task.

**Conventions for all tasks:**
- Build: `swift build` • Tests: `swift run LisperKitTests` • App: `./scripts/build.sh && open dist/Lisper.app`
- **Test framework amendment (Task 1 discovery):** this machine is CLT-only (no Xcode), so `swift test`/XCTest cannot execute. Tests use **Swift Testing** (`import Testing`, `@Suite`, `@Test`, `#expect`) inside the runnable `LisperKitTests` executable target (`Tests/LisperKitTests/`, entry point `TestMain.swift`). Translate the XCTest snippets in this plan mechanically: `XCTAssertEqual(a, b)` → `#expect(a == b)`; `XCTAssertTrue/False(x)` → `#expect(x)` / `#expect(!x)`; `XCTAssertNil(x)` → `#expect(x == nil)`; `XCTAssertEqual(a, b, accuracy: e)` → `#expect(abs(a - b) < e)`; `XCTFail("m")` → `Issue.record("m")`; `func testX() throws` → `@Test func testX() throws`; expected-throw `do { …; XCTFail() } catch SomeError.case {}` → `#expect(throws: SomeError.case) { … }` (or keep do/catch with `Issue.record`). `--filter` is not supported — always run the full suite.
- Commit after every task with the message given in the task.
- macOS platform target: `.macOS(.v15)`. Language mode v5 (avoid strict-concurrency churn).
- All UI is dark-only and uses `Theme` tokens (Task 9) — never hardcode colors elsewhere.

```bash
#!/bin/bash
# One-time: create a self-signed codesigning cert "Lisper Dev" in the login keychain
# so macOS permission grants (Accessibility/Microphone) survive rebuilds.
set -euo pipefail
ID="Lisper Dev"
if security find-identity -p codesigning -v 2>/dev/null | grep -q "$ID"; then
  echo "'$ID' already exists"; exit 0
fi
TMP=$(mktemp -d)
cat > "$TMP/cert.cnf" <<EOF
[req]
distinguished_name = dn
x509_extensions = ext
prompt = no
[dn]
CN = $ID
[ext]
keyUsage = critical,digitalSignature
extendedKeyUsage = critical,codeSigning
basicConstraints = critical,CA:false
EOF
openssl req -x509 -newkey rsa:2048 -keyout "$TMP/key.pem" -out "$TMP/cert.pem" \
  -days 3650 -nodes -config "$TMP/cert.cnf"
openssl pkcs12 -export -out "$TMP/cert.p12" -inkey "$TMP/key.pem" -in "$TMP/cert.pem" -passout pass:lisper
security import "$TMP/cert.p12" -k ~/Library/Keychains/login.keychain-db -P lisper -T /usr/bin/codesign
# Trust it for code signing (will prompt for your password once)
sudo security add-trusted-cert -d -r trustRoot -p codeSign -k /Library/Keychains/System.keychain "$TMP/cert.pem" \
  || echo "Trust step failed — you can trust the cert manually in Keychain Access (Get Info > Trust > Code Signing: Always Trust)"
rm -rf "$TMP"
echo "Created '$ID'. Rebuild with scripts/build.sh."
```

```swift
// Sources/LisperKit/Stats/FillerLexicon.swift
import Foundation

public enum FillerLexicon {
    /// Default crutch/filler phrases tracked by the coach. Multi-word phrases supported.
    public static let defaults: [String] = [
        "um", "uh", "erm", "like", "you know", "sort of", "kind of",
        "i mean", "basically", "actually", "literally", "right?", "okay so"
    ]

    /// Builds a case-insensitive word-boundary regex for a phrase.
    static func regex(for phrase: String) -> NSRegularExpression {
        let escaped = NSRegularExpression.escapedPattern(for: phrase)
            .replacingOccurrences(of: "\\ ", with: "\\s+")
        return try! NSRegularExpression(pattern: "\\b\(escaped)\\b", options: [.caseInsensitive])
    }
}
```

```swift
// Sources/LisperKit/Stats/TranscriptStats.swift
import Foundation

public struct TranscriptStats: Codable, Equatable {
    public let wordCount: Int
    public let fillerCounts: [String: Int]   // phrase -> occurrences (only non-zero)
    public let wordsPerMinute: Double
    public var fillerCount: Int { fillerCounts.values.reduce(0, +) }
    public var fillersPer100Words: Double {
        wordCount == 0 ? 0 : Double(fillerCount) / Double(wordCount) * 100
    }

    public static func compute(raw: String, durationSeconds: Double, customFillers: [String]) -> TranscriptStats {
        let words = raw.split { $0.isWhitespace || $0.isNewline }.count
        var counts: [String: Int] = [:]
        let phrases = Array(Set(FillerLexicon.defaults + customFillers.map { $0.lowercased() }))
        let range = NSRange(raw.startIndex..., in: raw)
        for phrase in phrases {
            let n = FillerLexicon.regex(for: phrase).numberOfMatches(in: raw, options: [], range: range)
            if n > 0 { counts[phrase] = n }
        }
        let wpm = durationSeconds > 0 ? Double(words) / (durationSeconds / 60) : 0
        return TranscriptStats(wordCount: words, fillerCounts: counts, wordsPerMinute: wpm)
    }
}
```

```swift
// Sources/LisperKit/Cleanup/RuleBasedCleanup.swift
import Foundation

/// Offline/no-key fallback: strips pure fillers, fixes spacing/casing.
/// Intentionally conservative — only removes words that are never content.
public enum RuleBasedCleanup {
    private static let strippable = ["um", "uh", "erm", "uhm", "you know", "i mean", "sort of", "kind of"]

    public static func clean(_ raw: String) -> String {
        var text = raw.trimmingCharacters(in: .whitespacesAndNewlines)
        guard !text.isEmpty else { return "" }

        for phrase in strippable {
            let re = FillerLexicon.regex(for: phrase)
            text = re.stringByReplacingMatches(in: text, options: [],
                range: NSRange(text.startIndex..., in: text), withTemplate: "")
        }
        // collapse whitespace, fix space-before-punctuation, drop doubled/orphaned punctuation
        text = text.replacingOccurrences(of: #"\s+"#, with: " ", options: .regularExpression)
        text = text.replacingOccurrences(of: #"\s+([,.!?;:])"#, with: "$1", options: .regularExpression)
        text = text.replacingOccurrences(of: #"([,.!?;:]){2,}"#, with: "$1", options: .regularExpression)
        text = text.replacingOccurrences(of: #"^[,.;:\s]+"#, with: "", options: .regularExpression)
        text = text.trimmingCharacters(in: .whitespaces)
        guard !text.isEmpty else { return "" }

        // capitalize sentence starts
        var result = ""
        var capitalizeNext = true
        for ch in text {
            if capitalizeNext, ch.isLetter {
                result.append(Character(ch.uppercased()))
                capitalizeNext = false
            } else {
                result.append(ch)
                if ".!?".contains(ch) { capitalizeNext = true }
            }
        }
        if let last = result.last, !".!?…".contains(last) { result.append(".") }
        return result
    }
}
```

```swift
// Sources/LisperKit/Store/LisperDatabase.swift
import Foundation
import GRDB

public struct DailyAggregate: Equatable {
    public let day: Date               // start of day
    public let sessionCount: Int
    public let totalWords: Int
    public let totalFillers: Int
    public let avgWPM: Double
    public var fillersPer100Words: Double {
        totalWords == 0 ? 0 : Double(totalFillers) / Double(totalWords) * 100
    }
}

public final class LisperDatabase: @unchecked Sendable {
    public let queue: DatabaseQueue

    /// Production DB at ~/Library/Application Support/Lisper/lisper.sqlite
    public static func standard() throws -> LisperDatabase {
        let dir = FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("Lisper", isDirectory: true)
        try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        let queue = try DatabaseQueue(path: dir.appendingPathComponent("lisper.sqlite").path)
        return try LisperDatabase(queue: queue)
    }

    public init(queue: DatabaseQueue) throws {
        self.queue = queue
        try migrate()
    }

    private func migrate() throws {
        var migrator = DatabaseMigrator()
        migrator.registerMigration("v1") { db in
            try db.create(table: "sessions") { t in
                t.autoIncrementedPrimaryKey("id")
                t.column("startedAt", .datetime).notNull().indexed()
                t.column("durationSeconds", .double).notNull()
                t.column("appBundleID", .text).notNull()
                t.column("appName", .text).notNull()
                t.column("rawTranscript", .text).notNull()
                t.column("cleanedText", .text).notNull()
                t.column("wordCount", .integer).notNull()
                t.column("fillerCount", .integer).notNull()
                t.column("fillersJSON", .text).notNull().defaults(to: "{}")
                t.column("wpm", .double).notNull()
                t.column("engineUsed", .text).notNull()
                t.column("cleanupUsed", .text).notNull()
                t.column("inserted", .boolean).notNull()
            }
            try db.create(table: "weekly_tips") { t in
                t.primaryKey("weekStart", .text)
                t.column("tipMarkdown", .text).notNull()
                t.column("generatedAt", .datetime).notNull()
            }
        }
        try migrator.migrate(queue)
    }

    @discardableResult
    public func save(session: SessionRecord) throws -> SessionRecord {
        var s = session
        try queue.write { try s.insert($0) }
        return s
    }

    public func recentSessions(limit: Int) throws -> [SessionRecord] {
        try queue.read {
            try SessionRecord.order(Column("startedAt").desc).limit(limit).fetchAll($0)
        }
    }

    public func searchSessions(query: String, limit: Int = 200) throws -> [SessionRecord] {
        try queue.read {
            try SessionRecord
                .filter(Column("cleanedText").like("%\(query)%") || Column("rawTranscript").like("%\(query)%"))
                .order(Column("startedAt").desc).limit(limit).fetchAll($0)
        }
    }

    public func sessions(since: Date) throws -> [SessionRecord] {
        try queue.read {
            try SessionRecord.filter(Column("startedAt") >= since)
                .order(Column("startedAt").asc).fetchAll($0)
        }
    }

    public func deleteSession(id: Int64) throws {
        _ = try queue.write { try SessionRecord.deleteOne($0, key: id) }
    }

    public func prune(retention: RetentionPolicy) throws {
        guard let days = retention.days else { return }
        let cutoff = Date().addingTimeInterval(Double(-days) * 86400)
        _ = try queue.write { try SessionRecord.filter(Column("startedAt") < cutoff).deleteAll($0) }
    }

    public func dailyAggregates(daysBack: Int) throws -> [DailyAggregate] {
        let since = Calendar.current.startOfDay(for: Date().addingTimeInterval(Double(-daysBack) * 86400))
        let sessions = try self.sessions(since: since)
        let grouped = Dictionary(grouping: sessions) { Calendar.current.startOfDay(for: $0.startedAt) }
        return grouped.keys.sorted().map { day in
            let group = grouped[day]!
            let words = group.reduce(0) { $0 + $1.wordCount }
            let fillers = group.reduce(0) { $0 + $1.fillerCount }
            let avgWPM = group.isEmpty ? 0 : group.reduce(0.0) { $0 + $1.wpm } / Double(group.count)
            return DailyAggregate(day: day, sessionCount: group.count, totalWords: words,
                                  totalFillers: fillers, avgWPM: avgWPM)
        }
    }

    public func save(tip: WeeklyTip) throws {
        try queue.write { try tip.save($0) }
    }

    public func tip(weekStart: String) throws -> WeeklyTip? {
        try queue.read { try WeeklyTip.fetchOne($0, key: weekStart) }
    }
}
```

```swift
/// Encodes mono Float32 PCM as 16-bit PCM WAV (what the Groq endpoint expects).
public enum WavEncoder {
    public static func encode(_ audio: CapturedAudio) -> Data {
        let sampleRate = UInt32(audio.sampleRate)
        let numSamples = audio.samples.count
        let dataSize = UInt32(numSamples * 2)
        var d = Data(capacity: 44 + numSamples * 2)

        func append(_ s: String) { d.append(contentsOf: s.utf8) }
        func append32(_ v: UInt32) { withUnsafeBytes(of: v.littleEndian) { d.append(contentsOf: $0) } }
        func append16(_ v: UInt16) { withUnsafeBytes(of: v.littleEndian) { d.append(contentsOf: $0) } }

        append("RIFF"); append32(36 + dataSize); append("WAVE")
        append("fmt "); append32(16); append16(1) /*PCM*/; append16(1) /*mono*/
        append32(sampleRate); append32(sampleRate * 2) /*byte rate*/
        append16(2) /*block align*/; append16(16) /*bits*/
        append("data"); append32(dataSize)

        for sample in audio.samples {
            let scaled = sample * 32768
            let value = Int16(max(Float(Int16.min), min(Float(Int16.max), scaled)))
            withUnsafeBytes(of: value.littleEndian) { d.append(contentsOf: $0) }
        }

    }
```

```swift
        req.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
        req.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type")

        func field(_ name: String, _ value: String) {
            body.append(contentsOf: "--\(boundary)\r\nContent-Disposition: form-data; name=\"\(name)\"\r\n\r\n\(value)\r\n".utf8)
        }

        body.append(wav)
        body.append(contentsOf: "\r\n--\(boundary)--\r\n".utf8)
        req.httpBody = body

        struct R: Decodable { let text: String }
        guard let decoded = try? JSONDecoder().decode(R.self, from: data) else {
            throw EngineError.badResponse(resp, String(data: data, encoding: .utf8) ?? "")
        }
        return decoded.text
    }

    public func chat(system: String, user: String, model: String, maxTokens: Int = 4096) async throws -> String {
        guard let url = URL(string: "\(baseURL)/chat/completions") else {
            throw EngineError.network("bad base URL")
        }
        var req = URLRequest(url: url, timeoutInterval: timeout)
        req.httpMethod = "POST"
        req.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        let payload: [String: Any] = [
            "model": model,
            "temperature": 0.2,
            "max_tokens": maxTokens,
            "messages": [
                ["role": "system", "content": system],
                ["role": "user", "content": user],
            ],
        ]
        req.httpBody = try JSONSerialization.data(withJSONObject: payload)

        let (data, resp) = try await send(req)
        struct R: Decodable {
            struct Choice: Decodable { struct Msg: Decodable { let content: String }; let message: Msg }
            let choices: [Choice]
        }
        guard let decoded = try? JSONDecoder().decode(R.self, from: data),
              let content = decoded.choices.first?.message.content else {
            throw EngineError.badResponse(resp, String(data: data, encoding: .utf8) ?? "")
        }
        return content.trimmingCharacters(in: .whitespacesAndNewlines)
    }

    private func send(_ req: URLRequest) async throws -> (Data, Int) {
        do {
            let (data, response) = try await URLSession.shared.data(for: req)
            let status = (response as? HTTPURLResponse)?.statusCode ?? 0
            guard (200..<300).contains(status) else {
                throw EngineError.badResponse(status, String(data: data, encoding: .utf8) ?? "")
            }
            return (data, status)
        } catch let e as EngineError { throw e }
        catch { throw EngineError.network(error.localizedDescription) }
    }
}
```

```swift
import Foundation

public enum PipelineError: Error, Equatable {
    case tooShort
    case allEnginesFailed(String)
}

public struct DictationOutcome: Sendable {
    public let rawTranscript: String
    public let cleanedText: String
    public let engineUsed: String
    public let cleanupUsed: String
    public let stats: TranscriptStats
    public let session: SessionRecord
}

/// Orchestrates: audio -> STT (with fallback) -> cleanup (with fallback) -> stats -> persist.
public final class DictationPipeline: @unchecked Sendable {
    private let primarySTT: TranscriptionEngine?
    private let fallbackSTT: TranscriptionEngine?
    private let llmCleanup: CleanupEngine?
    private let ruleCleanup: CleanupEngine
    private let database: LisperDatabase

    public init(primarySTT: TranscriptionEngine?, fallbackSTT: TranscriptionEngine?,
                llmCleanup: CleanupEngine?, ruleCleanup: CleanupEngine, database: LisperDatabase) {
        self.primarySTT = primarySTT; self.fallbackSTT = fallbackSTT
        self.llmCleanup = llmCleanup; self.ruleCleanup = ruleCleanup; self.database = database
    }

    public func process(audio: CapturedAudio, context: CleanupContext,
                        customFillers: [String]) async throws -> DictationOutcome {
        guard audio.durationSeconds >= 0.4 else { throw PipelineError.tooShort }
        let startedAt = Date()

        // 1) Transcribe with fallback
        var raw: String? = nil
        var engineUsed = ""
        var lastError = "no engines configured"
        for engine in [primarySTT, fallbackSTT].compactMap({ $0 }) {
            do {
                raw = try await engine.transcribe(audio: audio, dictionaryTerms: context.dictionaryTerms)
                engineUsed = engine.name
                break
            } catch {
                lastError = "\(engine.name): \(error)"
            }
        }
        guard let rawTranscript = raw, !rawTranscript.isEmpty else {
            throw PipelineError.allEnginesFailed(lastError)
        }

        // 2) Clean with fallback
        var cleaned: String
        var cleanupUsed: String
        if let llm = llmCleanup {
            do {
                cleaned = try await llm.clean(raw: rawTranscript, context: context)
                cleanupUsed = llm.name
            } catch {
                cleaned = try await ruleCleanup.clean(raw: rawTranscript, context: context)
                cleanupUsed = ruleCleanup.name
            }
        } else {
            cleaned = try await ruleCleanup.clean(raw: rawTranscript, context: context)
            cleanupUsed = ruleCleanup.name
        }

        // 3) Stats on RAW speech (the coach's source of truth)
        let stats = TranscriptStats.compute(raw: rawTranscript,
                                            durationSeconds: audio.durationSeconds,
                                            customFillers: customFillers)

        // 4) Persist
        let session = SessionRecord(
            id: nil, startedAt: startedAt, durationSeconds: audio.durationSeconds,
            appBundleID: context.bundleID, appName: context.appName,
            rawTranscript: rawTranscript, cleanedText: cleaned,
            wordCount: stats.wordCount, fillerCount: stats.fillerCount,
            fillersJSON: stats.fillerCounts, wpm: stats.wordsPerMinute,
            engineUsed: engineUsed, cleanupUsed: cleanupUsed, inserted: true)
        let saved = try database.save(session: session)

        return DictationOutcome(rawTranscript: rawTranscript, cleanedText: cleaned,
                                engineUsed: engineUsed, cleanupUsed: cleanupUsed,
                                stats: stats, session: saved)
    }
}
```

```swift
// Sources/Lisper/Audio/AudioRecorder.swift
import AVFoundation
import LisperKit

/// Captures mic audio while the hotkey is held: native format -> 16k mono Float32.
/// Emits RMS levels for the pill waveform. Audio lives only in memory.
final class AudioRecorder {
    private let engine = AVAudioEngine()
    private var samples: [Float] = []
    private var converter: AVAudioConverter?
    private let targetFormat = AVAudioFormat(commonFormat: .pcmFormatFloat32,
                                             sampleRate: 16_000, channels: 1, interleaved: false)!
    private let lock = NSLock()
    private(set) var isRecording = false
    var onLevel: ((Float) -> Void)?          // RMS 0...1, called on audio thread
    var maxDuration: TimeInterval = 300      // 5-minute cap
    var onAutoStop: (() -> Void)?            // fired when cap hit (main thread)

    func start() throws {
        guard !isRecording else { return }
        samples.removeAll(keepingCapacity: true)
        let input = engine.inputNode
        let inputFormat = input.outputFormat(forBus: 0)
        guard inputFormat.sampleRate > 0 else {
            throw EngineError.unavailable("no input device")
        }
        converter = AVAudioConverter(from: inputFormat, to: targetFormat)

        input.installTap(onBus: 0, bufferSize: 4096, format: inputFormat) { [weak self] buffer, _ in
            self?.consume(buffer: buffer)
        }
        engine.prepare()
        try engine.start()
        isRecording = true
    }

    /// Stops and returns everything captured.
    func stop() -> CapturedAudio {
        guard isRecording else { return CapturedAudio(samples: []) }
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        isRecording = false
        lock.lock(); defer { lock.unlock() }
        return CapturedAudio(samples: samples)
    }

    private func consume(buffer: AVAudioPCMBuffer) {
        guard let converter else { return }
        let ratio = targetFormat.sampleRate / buffer.format.sampleRate
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * ratio) + 16
        guard let out = AVAudioPCMBuffer(pcmFormat: targetFormat, frameCapacity: capacity) else { return }
        var fed = false
        converter.convert(to: out, error: nil) { _, status in
            if fed { status.pointee = .noDataNow; return nil }
            fed = true; status.pointee = .haveData; return buffer
        }
        guard let ch = out.floatChannelData, out.frameLength > 0 else { return }
        let chunk = Array(UnsafeBufferPointer(start: ch[0], count: Int(out.frameLength)))

        var rms: Float = 0
        for s in chunk { rms += s * s }
        rms = sqrt(rms / Float(max(chunk.count, 1)))
        onLevel?(min(1, rms * 8)) // perceptual boost for the waveform

        lock.lock()
        samples.append(contentsOf: chunk)
        let hitCap = Double(samples.count) / 16_000 >= maxDuration
        lock.unlock()
        if hitCap { DispatchQueue.main.async { [weak self] in self?.onAutoStop?() } }
    }
}
```

```swift
/// Free/offline fallback using Apple's on-device recognizer.
struct AppleSpeechEngine: TranscriptionEngine {
    let name = "apple"

    func transcribe(audio: CapturedAudio, dictionaryTerms: [String]) async throws -> String {
        let status = await withCheckedContinuation { (c: CheckedContinuation<SFSpeechRecognizerAuthorizationStatus, Never>) in
            SFSpeechRecognizer.requestAuthorization { c.resume(returning: $0) }
        }
        guard status == .authorized else { throw EngineError.unavailable("speech recognition not authorized") }
        guard let recognizer = SFSpeechRecognizer(locale: Locale(identifier: "en-US")),
              recognizer.isAvailable else {
            throw EngineError.unavailable("apple recognizer unavailable")
        }

        let request = SFSpeechAudioBufferRecognitionRequest()
        request.shouldReportPartialResults = false
        if recognizer.supportsOnDeviceRecognition { request.requiresOnDeviceRecognition = true }
        if !dictionaryTerms.isEmpty { request.contextualStrings = dictionaryTerms }

        // Feed captured samples as one buffer
        let format = AVAudioFormat(commonFormat: .pcmFormatFloat32, sampleRate: 16_000,
                                   channels: 1, interleaved: false)!
        let frames = AVAudioFrameCount(audio.samples.count)
        guard frames > 0, let buffer = AVAudioPCMBuffer(pcmFormat: format, frameCapacity: frames) else {
            throw EngineError.emptyTranscript
        }
        buffer.frameLength = frames
        audio.samples.withUnsafeBufferPointer { src in
            buffer.floatChannelData![0].update(from: src.baseAddress!, count: audio.samples.count)
        }
        request.append(buffer)
        request.endAudio()

        return try await withCheckedThrowingContinuation { (c: CheckedContinuation<String, Error>) in
            var finished = false
            recognizer.recognitionTask(with: request) { result, error in
                if finished { return }
                if let error {
                    finished = true
                    c.resume(throwing: EngineError.unavailable(error.localizedDescription))
                } else if let result, result.isFinal {
                    finished = true
                    let text = result.bestTranscription.formattedString
                        .trimmingCharacters(in: .whitespacesAndNewlines)
                    if text.isEmpty { c.resume(throwing: EngineError.emptyTranscript) }
                    else { c.resume(returning: text) }
                }
            }
        }
    }
}
```

```swift
// Sources/Lisper/Input/HotkeyMonitor.swift
import AppKit
import Carbon.HIToolbox
import LisperKit

/// Watches the configured key globally (and locally when Lisper is frontmost).
/// hold mode: onPress when key goes down, onRelease when it goes up.
/// toggle mode: alternating onPress/onRelease on each key-down.
final class HotkeyMonitor {
    var onPress: (() -> Void)?
    var onRelease: (() -> Void)?

    private var globalMonitors: [Any] = []
    private var localMonitors: [Any] = []
    private var keyIsDown = false
    private var toggledOn = false
    private(set) var hotkey: HotkeyChoice = .fn
    private(set) var mode: HotkeyMode = .hold
    var isPaused = false

    func configure(hotkey: HotkeyChoice, mode: HotkeyMode) {
        self.hotkey = hotkey
        self.mode = mode
        stop(); start()
    }

    func start() {
        let flagsHandler: (NSEvent) -> Void = { [weak self] e in self?.handleFlags(e) }
        let keyHandler: (NSEvent, Bool) -> Void = { [weak self] e, down in self?.handleKey(e, down: down) }

        globalMonitors.append(NSEvent.addGlobalMonitorForEvents(matching: .flagsChanged, handler: flagsHandler) as Any)
        globalMonitors.append(NSEvent.addGlobalMonitorForEvents(matching: .keyDown) { keyHandler($0, true) } as Any)
        globalMonitors.append(NSEvent.addGlobalMonitorForEvents(matching: .keyUp) { keyHandler($0, false) } as Any)
        localMonitors.append(NSEvent.addLocalMonitorForEvents(matching: .flagsChanged) { e in flagsHandler(e); return e } as Any)
        localMonitors.append(NSEvent.addLocalMonitorForEvents(matching: .keyDown) { e in keyHandler(e, true); return e } as Any)
        localMonitors.append(NSEvent.addLocalMonitorForEvents(matching: .keyUp) { e in keyHandler(e, false); return e } as Any)
    }

    func stop() {
        (globalMonitors + localMonitors).forEach { NSEvent.removeMonitor($0) }
        globalMonitors.removeAll(); localMonitors.removeAll()
        keyIsDown = false
    }

    private func handleFlags(_ event: NSEvent) {
        guard !isPaused else { return }
        let down: Bool
        switch hotkey {
        case .fn:
            down = event.modifierFlags.contains(.function) && event.keyCode == 63 // kVK_Function
        case .rightCommand:
            guard event.keyCode == 54 else { return }
            down = event.modifierFlags.contains(.command)
        case .rightOption:
            guard event.keyCode == 61 else { return }
            down = event.modifierFlags.contains(.option)
        default:
            return
        }
        transition(down: down)
    }

    private func handleKey(_ event: NSEvent, down: Bool) {
        guard !isPaused else { return }
        let code: UInt16
        switch hotkey {
        case .f13: code = 105
        case .f14: code = 107
        case .f15: code = 113
        default: return
        }
        guard event.keyCode == code else { return }
        transition(down: down)
    }

    private func transition(down: Bool) {
        switch mode {
        case .hold:
            if down, !keyIsDown { keyIsDown = true; onPress?() }
            else if !down, keyIsDown { keyIsDown = false; onRelease?() }
        case .toggle:
            if down {
                guard !keyIsDown else { return }   // ignore key-repeat
                keyIsDown = true
                toggledOn ? onRelease?() : onPress?()
                toggledOn.toggle()
            } else {
                keyIsDown = false
            }
        }
    }
}
```

Note on Fn: when the key goes down, `.function` is in `modifierFlags` with `keyCode == 63`; on release the same keyCode arrives without the flag — `down` computes false. Arrow keys etc. also set `.function`, which is why we require `keyCode == 63`. The toggle branch resets `keyIsDown` on key-up so the next press fires.

```swift
        pasteboard.setString(text, forType: .string)
```

```swift
import CoreGraphics

/// One-time generated monochrome noise tile for the film-grain overlay (spec §8).
enum NoiseTexture {
    static let shared: NSImage = generate(size: 256)

    private static func generate(size: Int) -> NSImage {
        var rng = SystemRandomNumberGenerator()
        var pixels = [UInt8](repeating: 0, count: size * size)
        for i in 0..<pixels.count { pixels[i] = UInt8.random(in: 0...255, using: &rng) }
        let data = CFDataCreate(nil, pixels, pixels.count)!
        let provider = CGDataProvider(data: data)!
        let cg = CGImage(width: size, height: size, bitsPerComponent: 8, bitsPerPixel: 8,
                         bytesPerRow: size, space: CGColorSpaceCreateDeviceGray(),
                         bitmapInfo: CGBitmapInfo(rawValue: CGImageAlphaInfo.none.rawValue),
                         provider: provider, decode: nil, shouldInterpolate: false,
                         intent: .defaultIntent)!
        return NSImage(cgImage: cg, size: NSSize(width: size, height: size))
    }
}
```

```swift
import AppKit
import SwiftUI

/// Floating, non-activating panel at the bottom-center of the active screen.
final class PillController {
    let model = PillModel()
    private var panel: NSPanel?
    private var hideTask: DispatchWorkItem?

    func show(phase: PillPhase) {
        hideTask?.cancel()
        model.phase = phase
        if panel == nil { makePanel() }
        position()
        panel?.orderFrontRegardless()
        if case .success = phase { scheduleHide(after: 1.2) }
        if case .error = phase { scheduleHide(after: 3.0) }
    }

    func hide() {
        hideTask?.cancel()
        model.phase = .hidden
        panel?.orderOut(nil)
    }

    private func scheduleHide(after seconds: TimeInterval) {
        let task = DispatchWorkItem { [weak self] in self?.hide() }
        hideTask = task
        DispatchQueue.main.asyncAfter(deadline: .now() + seconds, execute: task)
    }

    private func makePanel() {
        let p = NSPanel(contentRect: NSRect(x: 0, y: 0, width: 260, height: 56),
                        styleMask: [.borderless, .nonactivatingPanel],
                        backing: .buffered, defer: false)
        p.level = .statusBar
        p.isOpaque = false
        p.backgroundColor = .clear
        p.hasShadow = false
        p.ignoresMouseEvents = true
        p.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
        p.contentView = NSHostingView(rootView: PillView(model: model))
        panel = p
    }

    private func position() {
        guard let panel else { return }
        let screen = NSScreen.screens.first { NSMouseInRect(NSEvent.mouseLocation, $0.frame, false) }
            ?? NSScreen.main
        guard let frame = screen?.visibleFrame else { return }
        panel.setContentSize(panel.contentView?.fittingSize ?? NSSize(width: 260, height: 56))
        let size = panel.frame.size
        panel.setFrameOrigin(NSPoint(x: frame.midX - size.width / 2, y: frame.minY + 80))
```

```swift
// Sources/Lisper/AppEnvironment.swift
import Foundation
import LisperKit

/// Builds the pipeline from current settings. Rebuilt whenever settings change.
final class AppEnvironment {
    let settingsStore = SettingsStore()
    let database: LisperDatabase

    init() {
        database = (try? LisperDatabase.standard()) ?? (try! LisperDatabase(queue: .init()))
        try? database.prune(retention: settingsStore.settings.retention)
    }

    func makePipeline() -> DictationPipeline {
        let s = settingsStore.settings
        let apiKey = KeychainStore.loadAPIKey()

        var groqSTT: TranscriptionEngine? = nil
        var llm: CleanupEngine? = nil
        if let apiKey, !apiKey.isEmpty {
            let client = GroqClient(baseURL: s.groqBaseURL, apiKey: apiKey)
            groqSTT = GroqWhisperEngine(client: client, model: s.groqWhisperModel)
            if s.llmCleanupEnabled {
                llm = LLMCleanupEngine(client: client, model: s.groqChatModel)
            }
        }
        let apple = AppleSpeechEngine()
        let primary: TranscriptionEngine? = (s.sttEngine == .groq && groqSTT != nil) ? groqSTT : apple
        let fallback: TranscriptionEngine? = (s.sttEngine == .groq && groqSTT != nil) ? apple : nil
        return DictationPipeline(primarySTT: primary, fallbackSTT: fallback,
                                 llmCleanup: llm, ruleCleanup: RuleCleanupEngine(),
                                 database: database)
    }

    func cleanupContext() -> CleanupContext {
        let s = settingsStore.settings
        let front = TextInserter.frontmostApp()
        return CleanupContext(appName: front.name, bundleID: front.bundleID,
                              tone: s.toneRules.tone(forBundleID: front.bundleID),
                              dictionaryTerms: s.dictionaryTerms)
    }
}
```

```swift
import AppKit
import SwiftUI
import LisperKit

final class AppDelegate: NSObject, NSApplicationDelegate {
    let env = AppEnvironment()
    let menuBar = MenuBarController()
    let pill = PillController()
    let hotkey = HotkeyMonitor()
    let recorder = AudioRecorder()
    private var mainWindow: NSWindow?
    private var processing = false

    func applicationDidFinishLaunching(_ notification: Notification) {
        menuBar.install()
        menuBar.onOpenMain = { [weak self] in self?.openMainWindow() }
        menuBar.onTogglePause = { [weak self] paused in self?.hotkey.isPaused = paused }

        recorder.onLevel = { [weak self] level in
            DispatchQueue.main.async { self?.pill.model.push(level: level) }
        }
        recorder.onAutoStop = { [weak self] in self?.finishRecording() }

        hotkey.onPress = { [weak self] in self?.beginRecording() }
        hotkey.onRelease = { [weak self] in self?.finishRecording() }
        applySettings()

        let s = env.settingsStore.settings
        if !s.onboardingComplete || !PermissionsService.accessibilityGranted || !PermissionsService.microphoneGranted {
            openMainWindow()   // main window hosts onboarding until complete (Task 13)
            menuBar.set(state: .warning)
        }
    }

    func applySettings() {
        let s = env.settingsStore.settings
        hotkey.configure(hotkey: s.hotkey, mode: s.hotkeyMode)
    }

    private func beginRecording() {
        guard !processing, !recorder.isRecording else { return }
        guard PermissionsService.microphoneGranted else {
            pill.show(phase: .error("Grant microphone access in Settings"))
            menuBar.set(state: .warning)
            return
        }
        do {
            try recorder.start()
            menuBar.set(state: .recording)
            pill.show(phase: .listening)
        } catch {
            pill.show(phase: .error("Couldn't start the microphone"))
        }
    }

    private func finishRecording() {
        guard recorder.isRecording else { return }
        let audio = recorder.stop()
        let context = env.cleanupContext()   // capture frontmost app BEFORE any UI shifts
        menuBar.set(state: .processing)
        pill.show(phase: .processing)
        processing = true

        let pipeline = env.makePipeline()
        let fillers = env.settingsStore.settings.customFillers
        Task { @MainActor in
            defer {
                self.processing = false
                self.menuBar.set(state: .idle)
            }
            do {
                let outcome = try await pipeline.process(audio: audio, context: context, customFillers: fillers)
                let ok = TextInserter.insert(outcome.cleanedText)
                self.pill.show(phase: ok ? .success : .error("Blocked here — press ⌘V to paste"))
            } catch PipelineError.tooShort {
                self.pill.hide()
            } catch {
                self.pill.show(phase: .error("Couldn't transcribe — check connection/key"))
            }
        }
    }

    func openMainWindow() {
        if mainWindow == nil {
            let win = NSWindow(contentRect: NSRect(x: 0, y: 0, width: 960, height: 640),
                               styleMask: [.titled, .closable, .miniaturizable, .resizable, .fullSizeContentView],

            win.titleVisibility = .hidden

            win.isReleasedWhenClosed = false
            win.center()
            win.contentView = NSHostingView(rootView: MainWindowRootView(appDelegate: self))
            mainWindow = win
        }
        NSApp.activate(ignoringOtherApps: true)
        mainWindow?.makeKeyAndOrderFront(nil)
    }
```

```swift
import Foundation

public struct CrutchWord: Equatable, Identifiable {
    public let word: String
    public let count: Int
    public var id: String { word }
}

public struct AppUsage: Equatable, Identifiable {
    public let appName: String
    public let sessionCount: Int
    public let totalWords: Int
    public let totalFillers: Int
    public var id: String { appName }
    public var fillersPer100Words: Double {
        totalWords == 0 ? 0 : Double(totalFillers) / Double(totalWords) * 100
    }
}

public struct CoachSummary: Equatable {
    public let sessionCount: Int
    public let totalWords: Int
    public let totalFillers: Int
    public let avgWPM: Double
    public let topCrutchWords: [CrutchWord]
    public let daily: [DailyAggregate]
    public let appBreakdown: [AppUsage]      // sorted by fillersPer100Words desc ("where do you ramble?")
    public let longestCleanStreak: Int       // consecutive sessions < 3 fillers/100 words
    public var fillersPer100Words: Double {
        totalWords == 0 ? 0 : Double(totalFillers) / Double(totalWords) * 100
    }
}

public enum CoachMetrics {
    static let cleanThreshold = 3.0 // fillers per 100 words

    public static func summary(db: LisperDatabase, daysBack: Int) throws -> CoachSummary {
        let since = Calendar.current.startOfDay(for: Date().addingTimeInterval(Double(-daysBack) * 86400))
        let sessions = try db.sessions(since: since) // chronological asc
        var crutch: [String: Int] = [:]
        for s in sessions {
            for (word, n) in s.fillersJSON { crutch[word, default: 0] += n }
        }
        let top = crutch.map { CrutchWord(word: $0.key, count: $0.value) }
            .sorted { $0.count > $1.count }
            .prefix(6)
        let words = sessions.reduce(0) { $0 + $1.wordCount }
        let fillers = sessions.reduce(0) { $0 + $1.fillerCount }
        let wpm = sessions.isEmpty ? 0 : sessions.reduce(0.0) { $0 + $1.wpm } / Double(sessions.count)

        let byApp = Dictionary(grouping: sessions, by: { $0.appName }).map { name, group in
            AppUsage(appName: name, sessionCount: group.count,
                     totalWords: group.reduce(0) { $0 + $1.wordCount },
                     totalFillers: group.reduce(0) { $0 + $1.fillerCount })
        }.sorted { $0.fillersPer100Words > $1.fillersPer100Words }

        var streak = 0, best = 0
        for s in sessions {
            let rate = s.wordCount == 0 ? 0 : Double(s.fillerCount) / Double(s.wordCount) * 100
            if rate < cleanThreshold { streak += 1; best = max(best, streak) }
            else { streak = 0 }
        }

        return CoachSummary(sessionCount: sessions.count, totalWords: words, totalFillers: fillers,
                            avgWPM: wpm, topCrutchWords: Array(top),
                            daily: try db.dailyAggregates(daysBack: daysBack),
                            appBreakdown: byApp, longestCleanStreak: best)
    }

    /// ISO-8601 Monday of the week containing `date`, as "YYYY-MM-DD".
    public static func weekStartKey(for date: Date = Date()) -> String {
        var cal = Calendar(identifier: .iso8601)
        cal.timeZone = TimeZone.current
        let comps = cal.dateComponents([.yearForWeekOfYear, .weekOfYear], from: date)
        let monday = cal.date(from: comps)!
        let f = DateFormatter()
        f.dateFormat = "yyyy-MM-dd"
        f.timeZone = TimeZone.current
        return f.string(from: monday)
    }
}
```

```swift
import Foundation

/// One cheap LLM call per week over raw transcripts -> 2-3 coaching tips. Cached in DB.
public struct WeeklyTipGenerator: Sendable {
    let client: GroqClient
    let model: String
    public init(client: GroqClient, model: String) { self.client = client; self.model = model }

    public func tip(db: LisperDatabase) async throws -> WeeklyTip {
        let key = CoachMetrics.weekStartKey()
        if let cached = try db.tip(weekStart: key) { return cached }

        let summary = try CoachMetrics.summary(db: db, daysBack: 7)
        guard summary.sessionCount >= 3 else {
            throw EngineError.unavailable("not enough sessions this week yet")
        }
        let sessions = try db.sessions(since: Date().addingTimeInterval(-7 * 86400))
        let sample = sessions.suffix(30).map { "- \($0.rawTranscript.prefix(300))" }.joined(separator: "\n")
        let crutch = summary.topCrutchWords.map { "\($0.word) ×\($0.count)" }.joined(separator: ", ")

        let system = """
        You are a concise speaking coach. You see raw (uncleaned) dictation transcripts from one speaker's week.
        Give exactly 2-3 specific, actionable tips to speak more clearly with fewer fillers.
        Reference their actual patterns (quote a short example when useful). Suggest concrete replacement
        phrases or pauses. Friendly, direct, no fluff. Output plain markdown bullet points only.
        """
        let user = """
        This week: \(summary.sessionCount) dictations, \(summary.totalWords) words, \
        \(String(format: "%.1f", summary.fillersPer100Words)) fillers per 100 words, \
        avg \(Int(summary.avgWPM)) wpm. Top crutch words: \(crutch.isEmpty ? "none" : crutch).

        Raw transcript samples:
        \(sample)
        """
        let text = try await client.chat(system: system, user: user, model: model, maxTokens: 500)
        let tip = WeeklyTip(weekStart: key, tipMarkdown: text, generatedAt: Date())
        try db.save(tip: tip)
```

```swift
// Waveform glyph on the black/blue-glow/grain canvas (spec §8).
import AppKit

func drawIcon(size: CGFloat) -> NSImage {
    let img = NSImage(size: NSSize(width: size, height: size))
    img.lockFocus()
    let rect = NSRect(x: 0, y: 0, width: size, height: size)
    let path = NSBezierPath(roundedRect: rect, xRadius: size * 0.225, yRadius: size * 0.225)
    path.addClip()

    NSColor(srgbRed: 0.02, green: 0.024, blue: 0.031, alpha: 1).setFill()
    rect.fill()

    let glow = NSGradient(colors: [
        NSColor(srgbRed: 0.247, green: 0.714, blue: 1.0, alpha: 0.9),
        NSColor(srgbRed: 0.039, green: 0.4, blue: 1.0, alpha: 0.45),
        NSColor.clear])!
    glow.draw(fromCenter: NSPoint(x: size * 0.18, y: size * 0.12), radius: 0,
              toCenter: NSPoint(x: size * 0.18, y: size * 0.12), radius: size * 0.95, options: [])

    // grain
    for _ in 0..<Int(size * size * 0.02) {
        let x = CGFloat.random(in: 0..<size), y = CGFloat.random(in: 0..<size)
        NSColor.white.withAlphaComponent(CGFloat.random(in: 0...0.05)).setFill()
        NSRect(x: x, y: y, width: 1, height: 1).fill()
    }

    // waveform bars
    let bars: [CGFloat] = [0.22, 0.42, 0.68, 0.92, 0.6, 0.36, 0.2]
    let barW = size * 0.045
    let gap = size * 0.035
    let totalW = CGFloat(bars.count) * barW + CGFloat(bars.count - 1) * gap
    var x = (size - totalW) / 2
    for h in bars {
        let barH = size * 0.55 * h
        let bar = NSBezierPath(roundedRect: NSRect(x: x, y: (size - barH) / 2, width: barW, height: barH),
                               xRadius: barW / 2, yRadius: barW / 2)
        NSColor.white.setFill()
        bar.fill()
        x += barW + gap
    }
    img.unlockFocus()
    return img
}

let iconset = "Resources/AppIcon.iconset"
try? FileManager.default.removeItem(atPath: iconset)
try! FileManager.default.createDirectory(atPath: iconset, withIntermediateDirectories: true)
for (name, px) in [("16x16", 16), ("16x16@2x", 32), ("32x32", 32), ("32x32@2x", 64),
                   ("128x128", 128), ("128x128@2x", 256), ("256x256", 256), ("256x256@2x", 512),
                   ("512x512", 512), ("512x512@2x", 1024)] {
    let img = drawIcon(size: CGFloat(px))
    let rep = NSBitmapImageRep(data: img.tiffRepresentation!)!
    rep.size = NSSize(width: px, height: px)
    try! rep.representation(using: .png, properties: [:])!
        .write(to: URL(fileURLWithPath: "\(iconset)/icon_\(name).png"))
}
print("iconset written — converting to icns…")
let task = Process()
task.launchPath = "/usr/bin/iconutil"

task.launch(); task.waitUntilExit()
print(task.terminationStatus == 0 ? "Resources/AppIcon.icns ✓" : "iconutil failed")
```
